2. Ask the user for 2 numbers and display their arithmetic mean (average).
3. Ask the user for the side length of a square and display the area of that square.
4. Make a kilometers-to-miles converter: the user enters kilometers and the program displays miles. 1 km = 0.62 miles. Store this value in the code as a constant.
5. Make a calculator. The user enters two numbers, and the program displays the results of + - * / between them.
6. The user enters values a and b for the formula a * x + b = 0. The program calculates and displays x.
7. Ask the user for the current time (hours and minutes) and display how many hours and minutes are left until the next day.
8. Ask the user for a three-digit number and display its second digit. Use the % operator (remainder of division) to solve it.
9. Ask the user for a five-digit number and move its last digit to the front (12345 should become 51234).
10. An employee's salary is $250 + 10% of sales. Ask for the total sales for the month and calculate the salary.
