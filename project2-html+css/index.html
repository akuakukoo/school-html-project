HyperText Markup Language (HTML) is the standard markup language for documents designed to be displayed in a web browser.[1] It defines the meaning and structure of web content, and is often assisted by Cascading Style Sheets (CSS) and scripting languages such as JavaScript.[2]

History

In 1980, physicist Tim Berners-Lee proposed and prototyped a system for researchers to use and share documents. In 1989 he wrote a memo proposing an Internet-based hypertext system.[3] The first publicly available description of HTML was a document called "HTML Tags", first published in late 1991.

Elements

HTML documents are made up of elements. An element usually has a start tag and an end tag, with content in between.

Lists

Common structural elements include:

  • <div>, a generic container
  • <p>, a paragraph
  • <h1> to <h6>, headings

A typical workflow for writing a page:

  1. Write the markup
  2. Add styles with CSS
  3. Open it in a browser
